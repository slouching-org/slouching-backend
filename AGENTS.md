# AGENTS.md

Slouching's optional helper: an Elixir/OTP service that a crew member may
host for pairing rendezvous, an encrypted-copy mailbox and an experimental
SFU. The desktop client lives in `slouching-frontend`. The project overview,
canonical protobuf schema and cross-repository scripts live in `slouching`,
which pins this repository as the submodule `repositories/backend`.

The README and some fichas lag behind the code. Where they disagree, trust
the code.

## Commands

Run from `server/`:

```sh
mix deps.get --check-locked
mix format --check-formatted
mix compile --warnings-as-errors
mix test
mix setup              # deps.get, ecto.create, ecto.migrate --pool-size 1
mix run --no-halt      # serves http://127.0.0.1:3707
```

The first four are the CI gates (`.github/workflows/ci.yml`), which runs
them on Erlang/OTP 29.0.5 and Elixir 1.20.3.

- Compiling the dependencies needs a C toolchain, pkg-config and the OpenSSL
  headers (ex_dtls, unifex), a Rust toolchain (the ex_sctp NIF) and network
  access (ex_libsrtp downloads a precompiled libsrtp2).
- Tests use an in-memory SQLite database and do not start the HTTP listener.
- `scripts/smoke-local-sqlite.sh` and `scripts/smoke-release.sh` start a real
  server on a free loopback port. They need python3, curl and openssl and are
  not part of CI.

## Layout

| Path | Contents |
| --- | --- |
| `server/lib/slouching_server/router.ex` | Every HTTP route: health, status, pairing sessions, mailbox copies, `/ws` |
| `server/lib/slouching_server/handshake_socket.ex` | Binary protobuf WebSocket: device-key challenge, then SFU signaling |
| `server/lib/slouching_server/calls/` | SFU rooms, negotiation, peers and RTP forwarding |
| `server/lib/slouching_server/delivery/` | Mailbox storage, request signatures, quotas and expiry |
| `server/lib/slouching_server/pairing_sessions.ex` | In-memory SPAKE2 rendezvous |
| `server/lib/slouching/v1/handshake.pb.ex` | Generated by protoc-gen-elixir 0.17.0; do not edit by hand |
| `server/config/runtime.exs` | Listener, TLS and database environment variables; the SFU reads `SLOUCHING_SFU_*` in `calls/sfu_peer.ex` |
| `server/vendor/ex_webrtc/` | Vendored ex_webrtc 0.17.0 with a local SFU DataChannel fix |
| `proto/` | Copy of the handshake schema |
| `peer/` | Historical Rust scaffold, not the backend; it also binds port 3707 |
| `docs/fichas/` | Architecture notes and ADRs |

## Conventions

- Format with `mix format`. The formatter inputs exclude `server/vendor/`;
  keep changes to the vendored library minimal and never reformat it.
- ex_webrtc is a path dependency, so `mix.lock` must not contain an
  `ex_webrtc` entry. With one, every `mix deps.get` re-resolves its whole
  dependency subtree and rewrites the lock.
- SQLite is the default repository. `SlouchingServer.PostgresRepo` is used
  only when `SLOUCHING_DATABASE_URL` is set, and no test covers it.
- Run SQLite migrations with `--pool-size 1`.
- A non-loopback `SLOUCHING_BIND_IP` requires TLS. Keep that guard.
- The helper stores only ciphertext and public keys. It must never hold a
  member's private keys, create MLS Commits or decide group state.
- `proto/slouching/v1/handshake.proto` must stay byte-identical to the
  canonical file in `slouching`. Change it there first, then copy it here and
  to `slouching-frontend` and regenerate `handshake.pb.ex`.
- The root Cargo workspace exists for `peer/` and excludes the ex_sctp NIF
  crate that Mix builds under `server/deps/`.
- Commit subjects are short imperative sentences without a prefix.

## Known gaps

- There is no LICENSE file yet; the team has to choose one. The vendored
  ex_webrtc keeps its own Apache-2.0 licence.
- Hex reports security advisories for the locked bandit 1.12.5, ecto 3.14.2,
  protobuf 0.17.0, plug 1.20.3 and plug_crypto 2.2.0.
- With `SLOUCHING_DATABASE_URL` set, Ecto looks for migrations in
  `priv/postgres_repo/migrations`, which does not exist, so the PostgreSQL
  option currently applies none.
- The smoke scripts and the cross-repository end-to-end tests run only from
  `scripts/check-integration.sh` in `slouching`.
